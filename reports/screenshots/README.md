# BITS Virtual Lab Execution Screenshot

Place the screenshot of the assignment being executed on the **BITS Virtual Lab** in this
folder and name it `bits_virtual_lab.png`.

The screenshot must clearly show:

1. The BITS Virtual Lab desktop or browser session,
2. the project running inside it (the executed `notebooks/training.ipynb` or the Streamlit
   console at `localhost:8501`), and
3. a visible timestamp or session identifier.

The same image must be embedded in the submitted PDF, as required by Section 2.3 of the
assignment brief (worth 1 mark).
